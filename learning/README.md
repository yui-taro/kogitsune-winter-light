# 『こぎつねと冬の灯り』実装を学ぶためのノート

この資料は、この作品の設計書と動くコードを往復しながら読むためのものです。C++ を少し読めれば始められます。設計の意図、担当するコード、確かめ方を各章で対応させています。

## 最初に動かす

macOS では raylib 6.0 のビルド済みディレクトリを指定して、リポジトリのルートから実行します。`RAYLIB_DIR` を省くと `/private/tmp/jev-raylib-6.0` を使います。

```sh
make -C game test
make -C game RAYLIB_DIR=/path/to/raylib
make -C game run RAYLIB_DIR=/path/to/raylib
```

最初は巣の小枝に `E` で触れます。`WASD` または矢印で移動し、`C` で伏せ、左 Shift で走り、`Q` で足跡を払えます。操作全体は [ゲームの README](../game/README.md) にあります。

## 読み方の約束

- `design/` は「どうあるべきか」、`game/include/` と `game/src/` は「現在どう実装したか」です。差があれば現在のコードとテストを実測し、差を記録します。
- `Game` は世界の正解を持ちます。`Knowledge` は狛犬が観測済みのことだけを持ちます。この区別が最重要です。
- `Jev` は狛犬の**意図**を選びます。移動、視界、接触、捕獲はゲーム側が計算します。確率から行動を抽選しません。
- 今の画面は固定背景と透過画像を使う 2.5D 試作です。3D モデルや専用の歩行アニメーションはまだありません。Jev 本番 API の実応答と Windows 実機も未検証です。

## 用語

| 用語 | この作品での意味 |
| --- | --- |
| フレーム | ゲームを一度更新して描く単位。通常は毎秒 60 回を目標にする |
| `dt` | 前の更新からの秒数。速度に掛けて移動距離を求める |
| 世界状態 | 子狐と灯籠の本当の位置、場面、狛犬の状態など |
| 観測・知識 | 狛犬に見えた／聞こえた事実とその記憶 |
| 意図 | 「足跡を調べる」など、狛犬の次の行動方針 |
| CP-B / CP-C | 神社に入る前後のやり直し用スナップショット |
