# 『こぎつねと冬の灯り』タイトル画面案

## 伝えること

寒い巣から山の神社へ向かう、子狐の小さな旅。子狐の視線と雪道の曲線を、ただ一つの琥珀色の灯籠へつなぐ。石の狛犬を遠景に置き、灯りを持ち出す難しさを示す。結末や狛犬の変身はここでは見せない。

## 制作指示の要点

- 背景: 立体のある絵本映画風。橙色の子狐を左手前に、雪道と青い谷を経て、右奥の神社の灯籠へ視線を導く。灯籠の炎だけを琥珀色の光源にする。石の狛犬は一体だけ。上部中央にロゴ用の暗い夜空を残し、文字やUIを焼き込まない。
- ロゴ: 「こぎつねと」を小さく、「冬の灯り」を大きく二段組にする。日本語の文字を一字も欠かさず読める形にする。象牙色の文字と控えめな琥珀色、濃紺の縁。狐の尾と小さな炎を文字とは別の装飾として添える。背景は透明。

両素材は組み込みの imagegen で作成し、既存の子狐、灯籠、狛犬、雪の神社の設定画を参照した。ゲームの起動時に表示し、「はじめる」から字幕と読み上げ付きプロローグへ進む構成で実装した。
