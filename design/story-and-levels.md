# 『こぎつねと冬の灯り』物語・レベル設計書

版: 0.4／2026-10-07  
状態: **レビュー用草案。完成版に含める場面と、その導線・障害・構図・演出・結末条件を定義する。実装・画像生成の開始指示ではない。**

本書は[ゲーム設計書](game-design.md)で決めた遊びのルールを、巣から神社までの具体的な場面に配置したもの。物語の出来事は[ストーリー設計](../research/fox-story-design.md)、画面と描画の制約は[画面・実装方式案](../research/fox-visual-implementation.md)と[描画工程調査](../research/production/rendering-pipeline.md)を根拠にする。表記は[要件定義書](requirements.md)にそろえ、ユーザー決定済みを「確定」、本書で具体化した案を「提案」とする。

**本書で扱わないもの:** 地形の寸法・当たり判定の座標・足跡の寿命や視界距離などの数値、狛犬のJev入力の詳細、画風、制作日程。位置関係の図はすべて**模式図**で、背景画像や平面図の寸法を決めるものではない。正確な平面図は、本書のレビュー後に図面として作る（[必要な画像一覧](image-reference-list.md)の方針）。

## 1. 場面構成の結論

完成版は**6場面**で構成する。往路3場面、盗難1場面、復路1場面、結末1場面。復路は往路の場所を逆向きに再利用し、灯籠の光で遊びを変える。

| ID | 場面 | 種別 | 主な目的 | 狛犬 | 状態 |
| --- | --- | --- | --- | --- | --- |
| S0 | **序章: 壊れた巣** | 演出＋最初の操作 | 「誰のために、何を取りに行くか」を伝える | 登場しない | 提案 |
| S1 | **第一場: 杉の森と高台** | 操作の習得 | 四行動と「雪は行動を記録する」を覚える。狛犬の慎重さを予告する | 遠景のみ（演出） | 提案 |
| S2 | **第二場: 鳥居と鈴** | **最初のJev見せ場** | 狛犬が手掛かりを比べて判断する姿を見せ、初めて駆け引きする | Jev判断あり | 提案（P-07は確定） |
| S3 | **第三場: 境内で灯籠を取る** | ステルス本番 | 守られた灯籠に近づき、くわえる | Jev判断あり | 提案 |
| S4 | **第四場: 光る帰り道** | 復路ステルス | 灯籠の光を抱えたまま巣へ戻る | Jev判断あり | 提案 |
| S5 | **終章: 灯りを分ける** | 確定演出 | 狛犬が弟妹を見て火を分け、灯籠を戻す | 演技のみ（結末は固定） | 確定（D-10）、演出は提案 |

**S2とS3は同じ「神社エリア」の手前と奥**として画面を切り替えずにつなぐ（D-15）。狛犬は一体のまま両方を行き来し、位置と記憶を引き継ぐ。カメラを平行移動だけで追尾する方法は検証する案。最初の検証単位である「境内1画面」（[要件 3章](requirements.md)）を、完成版のS2・S3の原型にする。

**総プレイ時間は未決定**（D-05）。場面ごとの所要分数は置かない。ただし、**S0とS1は初見のプレイヤーが寄り道なしに進めば、合計10分を大きく下回る量**に抑え、S2到着時に最初のJev判断が起きる構成とする（P-07）。[旧ストーリー設計](../research/fox-story-design.md)の分数は参考値として扱わない。

## 2. 世界の地図（模式図）

```text
                                    ┌──────── 神社エリア（S2・S3） ────────┐
 [巣]──雪の小道──[杉の森]──[高台]──[森の出口]──参道──[鳥居・鈴]──[境内]──[台座・灯籠]──[社]
   ▲赤い布          │                                     ▲
                    └──────── 倒木の抜け道 ──────────────┘（境内の右側へ出る）
```

| 地点 | 物語上の役割 | 遊びの役割 |
| --- | --- | --- |
| **巣** | 弟妹と冷たい小枝がある。入口に赤い布 | 開始・結末の場所。復路の最終目標 |
| **杉の森** | 吹雪の夜の山道 | 操作を覚える。復路では隠れ場所が光で変わる |
| **高台** | 巣の赤い布と神社の灯りが**両方見える**唯一の地点 | 距離感と目的を示す。終章では狛犬が巣の灯りを見つける地点になる |
| **鳥居・鈴** | 神社の入口。風でも鳴る鈴 | 最初のJev見せ場。正面の出入口 |
| **倒木の抜け道** | 子狐の体だからこそ通れる低い道 | 鳥居を通らない第二の出入口（F-06） |
| **境内・台座** | 石の狛犬が戻る低い定位置と、山道を照らす灯籠の台座を別に置く | 盗難と守り手の変化・帰還の舞台 |

**二つの出入口（D-16）:** 神社エリアと森の間を「鳥居」と「倒木の抜け道」でつなぐ。狛犬が一方を警戒する時、子狐がもう一方を選べる構造にする。山犬は低い倒木の下を通れないが、周囲を回って追える。二つあるだけで安全が保証されるわけではないため、遮蔽物・距離・足跡を含め、どの合法な狛犬判断でも[ゲーム設計 6章](game-design.md)の対処手段または納得できる再挑戦が残るか試遊で確かめる。

### 灯籠の置き場所（D-15で決定）

[ストーリー設計](../research/fox-story-design.md)では灯籠を「神社の門に掛ける」としていたが、[ゲーム設計書](game-design.md)と[必要な画像一覧](image-reference-list.md)は「台座」を前提にしている。D-15により**社の前の石の台座に置く**と決定した。狛犬の持ち場とは別に置き、盗んだ後の「空の台座」が手掛かりとしてはっきり見えるようにする。両者が同じ構図に収まるかは画面で検証する。

境内には、盗む灯籠と見間違える形の石灯籠などの発光物を置かない。画面の中で光るものは灯籠一つに絞り、目標を一目で分かるようにする。

## 3. 場面をまたいで変わる状態

| 状態 | S0 | S1 | S2 | S3 | S4 | S5 |
| --- | --- | --- | --- | --- | --- | --- |
| 灯籠 | 台座（遠景で光る） | 台座 | 台座 | 台座 → 狐の口 | 狐の口／狐が置いた場所 | 巣 → 狛犬が神社へ戻す |
| 神社の明るさ | 明るい（遠景） | 明るい | 明るい | 盗難で暗くなる | 暗い | 夜明けに再び灯る |
| 狐の周囲の光 | なし | なし | なし | 盗難後に灯籠の光 | 灯籠の光（置けば消える） | 巣が暖色に |
| 雪と足跡 | 吹き込む雪 | 足跡を覚える | 足跡が手掛かり | 足跡が手掛かり | 往路の古い跡＋新しい跡 | 演出のみ |
| 守り手の姿 | 登場しない | 遠景で石→山犬→石（演出） | 定位置では石、持ち場を離れると山犬 | その時の居場所と判断に応じる | 灯籠を探す間は山犬。持ち場へ戻れば石 | 火を分ける時は山犬。灯籠を戻した後、定位置で石 |
| 狛犬の記憶 | なし | なし | 観測開始 | S2から引き継ぐ | S2・S3から引き継ぐ | 到着の仕方に反映 |
| 吹雪 | 強い（演出） | 弱め | 弱め | 弱め | 強まる | 止む → 夜明け |

狛犬の記憶は、狛犬自身が神社エリアで見聞きしたことから始まる。S1の遠景の狛犬は演出で、狐の行動を観測しない。往路の森で残した足跡は、狛犬が復路で森に入って実際に見た時だけ手掛かりになる。

## 4. 場面別の設計

各場面に、開始状態・終了条件・導線・障害・カメラ・必須演出・失敗時の扱い・必要な素材を定める。

### S0 序章: 壊れた巣

| 項目 | 内容 |
| --- | --- |
| 目的 | 目的を文章なしで伝える（E-01、P-01） |
| 開始状態 | 新規プレイ開始。巣の中、吹雪の夜 |
| 流れ | ①吹雪が巣の覆いをはがし、雪が吹き込む → ②弟妹が子狐の尾の下へ潜る → ③**操作開始**: 子狐が「触れる」で小枝を鼻で寄せるが、火はつかない → ④カメラが子狐の視線に沿って、山の上の神社の灯りへ上がる → ⑤短い目標表示「灯りを持って帰ろう」 → 巣の出口へ |
| 終了条件 | 子狐が巣の出口を出る → S1へ |
| 導線・障害 | 一本道。障害なし |
| カメラ | 巣の固定構図。③の後、灯りを見上げる別カメラの近景（P-06） |
| 操作の学習 | 移動、「触れる」（対象を示してから押す） |
| 右下HUD | 冒頭演出中は薄く、③の操作開始で四つとも表示する。初めから同じ位置 |
| 失敗 | なし |
| 必要な素材 | 巣の背景（E-03）、子狐（C-01〜03）、弟妹（C-04）、赤い布・小枝（P-02）、神社の灯り遠景、近景用の別カメラレンダー |

最初の「触れる」を、弟妹のために小枝を寄せる行為にすることで、操作の練習と動機の提示を一度に済ませる。

### S1 第一場: 杉の森と高台

| 項目 | 内容 |
| --- | --- |
| 目的 | 四行動と足跡の仕組みを学ぶ。狛犬が足跡を調べる性格だと予告する。巣と神社の距離感を見せる |
| 開始状態 | 巣の出口。狛犬は遠景のみ |
| 終了条件 | 森の出口（参道の手前の観察点）に着く → S2 |
| 導線 | ほぼ一本道。寄り道は短い行き止まりに限る |
| 狛犬 | 判断なし。狐の行動を観測しない |

**学習の並び（提案）:**

1. **歩く → 足跡:** 新しい雪原を歩くと、後ろに跡が残る様子をカメラに収める。文字は最小限。
2. **伏せる:** 低い倒木の下をくぐらないと進めない。狐の小さな体がそのまま道になることを見せる。
3. **走る:** 吹き溜まりのない開けた雪原。速いが足音が大きく、跡も深く残ることを見て分かるようにする。
4. **高台:** 振り返ると巣の赤い布、前を見ると神社の灯りが同じ画面に入る。遠くで**石の狛犬が山犬となって野うさぎの跡を前足で確かめ、持ち場へ戻って石になる**様子が見える（演出）。プレイヤーは「守り手は調べると決めた時に動物の姿になる」「役目が落ち着くと戻る」と知る。
5. **尾で払う:** 高台の後、森の出口の手前で自分の足跡を消せることを示す。払うと雪が舞い、跡がならされる。

| 項目 | 内容 |
| --- | --- |
| カメラ | 区間ごとの固定斜め見下ろし。狐を中央やや左に置いて平行移動で追う。高台だけ遠景を広く取る構図 |
| 失敗 | なし。狛犬に見つかることも起きない |
| 必要な素材 | 森と鳥居の背景（E-02）の森部分、高台の遠景（巣と神社が両方入る）、倒木、野うさぎの跡、子狐の歩き・伏せ・走り・尾で払う（C-03）、狛犬の遠景の調べる動作（C-06） |

高台の構図はS5で再び使う。終章で狛犬がここから巣の灯りを見つけるため、往路で必ず通る場所に置く。

### S2 第二場: 鳥居と鈴（最初のJev見せ場）

| 項目 | 内容 |
| --- | --- |
| 目的 | 狛犬が「鈴・足跡・灯籠」を比べて判断する姿を見せる（P-07、E-03、E-04） |
| 開始状態 | 参道の手前の観察点（杉の陰）。ここから鳥居越しに境内の台座・灯籠・狛犬が見える。狛犬は持ち場にいる |
| 終了条件 | 狐が鳥居、または倒木の抜け道を通って境内に入る → S3（画面の切り替えなし） |

**神社エリアの配置（模式図）:**

```text
                         [ 社 ]
                           │
     [左の杉並木]     [台座・灯籠]      [右の植え込み]
          ║              ◎狛犬の持ち場          │
          ║                              [倒木の抜け道の出口]
   ───────╨──────[ 鳥居・鈴 ]───────────────────┘
                     │参道
              [観察点（杉の陰）]  ← 森の出口から
```

**場面の流れ（提案）:**

1. 観察点に着くと、**風で鈴が一度鳴る**。これはプレイヤーが何もしなくても狛犬の最初の判断を見られる共通のきっかけ（[ゲーム設計 7章](game-design.md)）。
2. 石の狛犬は耳を鳥居へ向け、灯籠を見直してから行動を選ぶ。**門を守る**なら石のまま留まり、「考えて残った」ことを耳と視線で示す。**持ち場を離れる**なら山犬に変わる予兆を見せ、プレイヤーが動き出す前に読めるようにする。
3. プレイヤーは状況を見て工作を選ぶ。
   - 鈴を鳴らす（鳥居の柱に近づく必要があり、狛犬の視界に入りやすい）
   - 右の倒木の抜け道へ向かって、わざと足跡を残す／消す
   - 左の杉並木を伏せて進む
4. 狛犬の選択によって通りやすい道が変わる。

| 狛犬の選択（候補例） | 開く道 | 残るリスク |
| --- | --- | --- |
| 門を守る（持ち場に残る） | 左の杉並木を伏せて回る、または倒木の抜け道 | 時間がかかる。抜け道の雪に跡が残る |
| 鈴を確かめる（鳥居へ来る） | 狛犬が鳥居へ来る間に、右の抜け道から境内へ | 観察点が鳥居に近い。先に隠れないと見つかる |
| 足跡を調べる（右へ行く） | 正面の鳥居、または左の杉並木 | 狛犬は空振りを記憶する。同じ囮は次に効きにくい |

| 項目 | 内容 |
| --- | --- |
| Jevを呼ぶ契機（案） | 風の鈴、狐が鳴らした鈴、狛犬が足跡を見つけた時、調べた先で空振りした時。詳細は`komainu-jev.md` |
| カメラ | 観察点から鳥居・台座・狛犬が同時に入る構図。右下のHUD領域には重要物を置かない。境内へ入ると平行移動でS3の構図へ |
| 近景演出（P-06） | 狛犬の初登場。観察点に着いた直後、短く狛犬の顔と雪をかぶった石肌を見せる。見せた後に操作へ戻る |
| 失敗 | 狛犬に見つかって捕まると、観察点（CP-B）から再挑戦 |
| 必要な素材 | 森と鳥居の背景（E-02）の鳥居部分、境内の背景（E-01）、鈴・倒木（P-02）、狛犬の見張る・耳を向ける・調べる・追う（C-05、C-06）、鈴の音と揺れ、近景用の別カメラレンダー |

**10分以内の確認:** 初見のプレイヤーがS0から普通に進み、手順1の鈴と狛犬の判断を10分以内に見られるかを観察する。届かない場合は、S0の演出、S1の学習の数、分岐の長さの順に削る。

### S3 第三場: 境内で灯籠を取る

| 項目 | 内容 |
| --- | --- |
| 目的 | 守られた灯籠を盗む緊張と達成。盗難で世界の見え方を変える |
| 開始状態 | 狐は境内の中。狛犬の位置と記憶はS2の結果のまま |
| 終了条件 | 灯籠をくわえて、鳥居または倒木の抜け道から神社エリアを出る → S4 |

**境内の要素（提案）:**

| 要素 | 役割 |
| --- | --- |
| 台座と灯籠 | 目標。近づくと「触れる」が「くわえる」に変わる |
| 社の床下 | 伏せて入れる隠れ場所。外から見えにくいが、入口の雪に跡が残る |
| 左の杉並木、右の植え込み | 遮蔽物。前景と奥景に分け、前後を通れることを見せる |
| 二つの出口（D-16） | 鳥居（正面、開けている）と倒木の抜け道（子狐が伏せて通る低い道）。山犬は倒木の下を通れず迂回する |

**盗む瞬間（必須演出）:** 灯籠をくわえると台座が暗くなり、鳥居の影が広がる。音楽を止め、風と鎖の音だけにする。近景（P-06）で灯籠の重さに首が下がる子狐を見せる。演出はごく短くし、狛犬の位置はそのプレイの判断結果のままにする。毎回同じ方向から狛犬が飛び出す演出にはしない。

**盗難の発覚:** 狛犬は空の台座、運ばれる光、狐の姿のいずれかを実際に見た時だけ盗難を知る。知った時は台座の前で止まり、出口と光の方向を見る。

| 盗難後の狛犬の選択（候補例） | 狐の対処 |
| --- | --- |
| 最後に見た場所を調べる | 別の出口へ向かう。社の床下で光を隠してやり過ごす |
| 出口を警戒する | 警戒されていない方の出口を使う（二つの出口の保証） |
| 光を追う | 灯籠を一度置いて囮にし、身軽に離れる。置いた灯籠は後で取りに戻る必要がある |

| 項目 | 内容 |
| --- | --- |
| カメラ | 台座を中心に、鳥居と倒木の出口が両方入る構図。HUD領域は空ける |
| 失敗 | 盗む前に捕まった場合はCP-B（観察点）から。盗んだ後に捕まった場合は灯籠が台座に戻り、CP-C（境内入口近くの隠れ場所）から |
| 必要な素材 | 境内の背景（E-01）、灯籠の点灯・消灯（P-01）、盗難前後の明暗比較（E-04）、社の床下、子狐が灯籠をくわえる（C-03）、狛犬が台座を見て止まる動作、近景用の別カメラレンダー |

### S4 第四場: 光る帰り道

| 項目 | 内容 |
| --- | --- |
| 目的 | 盗んだ達成感を新しい緊張へつなげる。同じ道が別の問題になる |
| 開始状態 | 灯籠をくわえて神社エリアを出た直後。神社は暗く、吹雪が強まる |
| 終了条件 | 灯籠を持って巣に入る → S5。巣は安全地帯で、入った時点で捕獲は起きない |
| 導線 | 森の出口 → 杉の森（往路と同じ場所） → 高台 → 雪の小道 → 巣 |

**往路からの変化:**

| 往路での役割 | 復路での変化 |
| --- | --- |
| 杉の陰は暗く安全な隠れ場所 | 灯籠の光が漏れ、近くの雪と幹が照らされる。完全には隠れられない |
| 倒木の下は伏せて通る近道 | 灯籠をくわえたままでは遅く、光が下から漏れる |
| 足跡は消せば安全 | 往路の古い跡は薄れて残る。新しい跡と光が重なる |
| 森は暗くて道に迷いやすい | 灯籠の光が道しるべになる一方、狛犬にとっての目印にもなる |
| 開けた雪原は走って抜ける | 吹雪で視界が切れる間を使って横切る（追加候補） |

**灯籠を置く選択:** 狐は灯籠を置いて身軽になれる。置いた灯籠の光は狛犬の手掛かりになり、取りに戻るまで巣には届かない。灯籠を置いたまま巣へ戻っても結末は始まらず、弟妹は寒いままである。狛犬が置かれた灯籠を見つけた場合は台座へ持ち帰る。その場合、狐は神社エリアから盗み直す。

**狛犬の追跡:** 狛犬は神社エリアで最後に得た手掛かり（光の方向、出口、足跡）から森へ入る。森では、実際に見た足跡と光だけを使って捜索先を選ぶ。巣の場所は知らないので、巣へ直行しない（A-01）。

| 項目 | 内容 |
| --- | --- |
| カメラ | 往路と同じ固定構図を再利用し、照明と雪だけを変える。巣の手前で、赤い布が見えたら目的地が近いと分かる構図にする |
| 失敗 | 捕まると灯籠は台座に戻り、CP-Cから再挑戦 |
| 必要な素材 | 森の背景（E-02）の夜・吹雪強め版、灯籠を運ぶ時の光の合成（E-04、[描画工程の難所](../research/production/rendering-pipeline.md)）、子狐が灯籠を運ぶ歩き・伏せ・走り・置く、狛犬の追う・捜す動作 |

S4は描画方式の最大の未検証点（運ばれる灯籠の光と、レンダー済みの毛・雪・石がなじむか）を最も多く使う場面。S3で光の表現が成立してから森へ広げる。

### S5 終章: 灯りを分ける

| 項目 | 内容 |
| --- | --- |
| 目的 | 子狐の目的と狛犬の役目を両立させる一つの結末（P-05、D-10） |
| 開始状態 | 子狐が灯籠を持って巣に入った |
| 終了条件 | 夜明けの場面を見せた後、エンディングへ |
| 操作 | 最初だけ「触れる」で灯籠を弟妹のそばに置く。その後は演出 |

**狛犬が巣に着く理由（因果の保証）:** 狛犬は巣の場所を知らないため、到着は狛犬が実際に得た手掛かりで説明できなければならない。

| 子狐が巣に入った時の狛犬 | 到着の流れ | 到着の演技 |
| --- | --- | --- |
| 狐か光を視界に捉えて追っていた | そのまま追跡して巣に着く | 荒い足取り、強い前進 |
| 見失っていた | 最後の手掛かりから森を進み、**高台で巣の灯りを見つける**。この「見る」ことが巣を知る観測になる | 遠くから光を見つけ、静かに歩いてくる |

いずれの場合も、ゲーム側が狛犬の移動を高台か巣まで進める。Jevの選択が巣への到着を妨げないよう、この区間の行動はゲームが決める。神社が暗い間、狛犬が灯籠を探し続けるのは任務に沿った自然な行動であり、高台は往路で狐も見た「巣と神社が両方見える場所」のため、プレイヤーにも理由が伝わる。

**必須演出の順番（[ストーリー設計 6章](../research/fox-story-design.md)を確定扱いにする提案）:**

1. 灯籠を弟妹のそばに置く。巣が暖まり、弟妹が寄ってくる。神社の方角は暗いまま。
2. 狛犬が到着する（上の表の演技差）。子狐は弟妹の前に立つ。
3. 狛犬が灯籠、小枝、弟妹を順に見る。足音が止まり、体が低くなる。
4. 伸ばした前足を一度止め、狐に危害を加えずに灯籠の蓋を開く。
5. 小枝に火が移り、弟妹が近づく。
6. 山犬は灯籠をくわえて神社へ戻る。子狐は巣の中からその背中を見る。
7. 灯籠を台座へ戻した山犬は、隣の低い定位置へ歩いて戻り、同じ姿勢で石の狛犬になる。
8. 夜明け。高台の構図で、神社と巣の両方に灯りがある。

| 項目 | 内容 |
| --- | --- |
| Jevの扱い | 結末はJevに選ばせない。到着の演技差はゲームが保存した記録から選ぶ。演技の一部にJevを使うかは`komainu-jev.md`で決める |
| カメラ | 巣の固定構図 → 3〜5は近景（P-06） → 7は神社の短い帰還画面 → 8は高台の遠景 |
| 失敗 | なし |
| 必要な素材 | 巣の背景の暖色版（E-03）、山犬のためらう・蓋を開ける・火を分ける・灯籠をくわえて去る、定位置で石に戻る演出（C-06）、火が移る音、夜明けの高台、近景用の別カメラレンダー |

## 5. チェックポイントと再挑戦

| ID | 位置 | 使う状況 | 灯籠 | 狛犬 |
| --- | --- | --- | --- | --- |
| CP-A | 巣の出口 | S0・S1の再開（失敗は起きないので、主にアプリ再開用） | 台座 | 持ち場 |
| CP-B | 参道手前の観察点 | S2・S3で、盗む前に捕まった時 | 台座 | 持ち場へ戻り石になる |
| CP-C | 境内入口近くの安全な隠れ場所。盗む前に保存 | S3・S4で、盗んだ後に捕まった時 | 保存時点の台座上へ戻る | S2からの観測・記憶を含む保存時点の位置・姿へ戻る |

- **捕獲の演出:** 狛犬は狐を傷つけず、くわえて境内の外へ置くか、灯籠を取り上げる。暗転は短くし、すぐ操作に戻す。
- **狛犬の記憶（D-18）:** 捕獲後は観測・記憶をCP保存時点へ戻す。同じ挑戦中に実際に経験した空振りは覚えるが、失敗した挑戦でCP保存以降に得た記憶は次の挑戦へ持ち越さない。CP-C保存前にS2で得た情報はCP-Cの記録に残る。
- **CP-Cからの再挑戦が長すぎる問題:** 森の奥で捕まると、神社から盗み直して戻ることになる。試遊で負担が大きければ、灯籠を戻す規則を保ったまま復路の距離を短くするか、森に二つ目の隠れ場所を置く。
- アプリを終了した後の再開（G-04、D-12）は、上の三地点を保存位置の候補とする。採否は`basic-design.md`で決める。

## 9. レビューで見てほしいこと

1. S0とS1が、初見で10分以内にS2の鈴の場面へ着ける短さになっているか。
2. S2で、狛犬がどの候補を選んでも狐に対処の道が残っているか（二つの出入口、遮蔽物）。
3. 盗難の前後で、S3とS4の遊びが本当に変わるか。
4. 狛犬が巣に着く理由が、狛犬自身の観測で説明できているか（特に高台）。
5. 確定した神社エリアのつながりと台座の位置が、実画面で分かりやすく見えるか。
