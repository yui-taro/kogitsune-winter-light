## 見た目の共通ルール

- 立体感のある絵本映画の画風。雪の青と灯籠の琥珀色を一貫させる。
- 主役は橙色の子狐。弟妹は小さい二匹で、濃い栗色と淡い杏色。
- 守り手は同じ一体が石の狛犬と灰色の山犬に姿を変える。二体として描かない。
- 灯籠は取っ手と開閉する蓋がある小さな角形。炎は一つ。
- 各イラストは文字を入れず、添える文は表示時に別レイヤーで載せる。

物語の根拠: [物語・レベル設計書](../story-and-levels.md) S0〜S5。既存の子狐、弟妹、守り手、灯籠の設定画を制作時の参照とする。

画像は組み込みの imagegen で生成。各場面の生成指示は上の「絵に必ず入れるもの」と共通ルールを英語にしたもので、既存の子狐・弟妹・狛犬・灯籠の画像を参照した。各画像は単独の横長16:9イラストで、文字・コマ割り・余計なキャラクターを入れない指定とした。7枚の通し絵全体はゲームへ組み込んでいない。

## ゲーム冒頭用の構成

結末を見せる上記7枚とは別に、ゲーム冒頭では巣にいる時点までを紹介する。巣の絵と、[巣から神社を見上げる絵](prologue-shrine-from-den-v1.png)を使う。子狐がまだ出発していない位置関係を保つ。

| 画面 | 字幕と読み上げ |
| --- | --- |
| 寒い巣 | 吹雪の夜、巣が壊れた。小さな弟と妹は、寒さに震えている。 |
| 小枝に寄る構図 | 暖めるための小枝はある。でも、火がない。 |
| 巣から見える神社 | 山の神社には灯りがある。けれど、狛犬がそれを守っている。 |
| 同じ巣と神社の構図 | 子狐は、火を巣まで持ち帰れるのか？ |

問いの後に同じ巣で操作を開始する。ここでは小枝に触れても火がつかないことをプレイヤーが確かめ、その後で神社へ向かう。冒頭用イラストは組み込みの imagegen で生成し、上記の既存設定画を参照した。音声は字幕と同じ文を macOS の Kyoko 音声で収録した。
