# 実装と検証の現在地

更新: 2026-10-07。ここでは設計草案の完成度と、動く試作の到達点を分けて記録します。詳細な操作・ビルド手順は [ゲーム README](../game/README.md)、実装を学ぶ順序は [学習ノート](../learning/README.md) にあります。

| 項目 | 現在の状態 | 根拠・次に確認すること |
| --- | --- | --- |
| 巣 → 森 → 神社 → 森 → 巣の進行 | C++ の状態テストで結末まで到達 | `tests/test_world.cpp` の `FullStoryReachesEnding` |
| 鳥居・倒木の二経路 | 両経路を実装。巣・森・神社の歩行範囲を背景の道に合わせ、狛犬の倒木迂回も実装 | `OffTrailMovementIsBlocked`、`PlayableRightRoute`、`GuardianWalksAroundLowPassage`。初見プレイで導線を確認する |
| 狛犬の観測と性格に沿う行動 | 観測境界、合法候補、決定的なローカル方針を実装 | `tests/test_contract.cpp`。本番 Jev の固定盤面評価は未実施 |
| Jev 中継 | TypeSafe Choice を呼ぶ中継と非同期クライアントを実装 | 模擬中継との HTTP 試験は通過。本番 API キーでの応答は未検証 |
| CP-B／CP-C | 狛犬の記憶を含む状態復元と古い返信の拒否を実装 | `CheckpointRestoresWholeSnapshot` 等で検証 |
| 画面・音・入力 | 固定背景、透過スプライト、HUD、合成効果音を実装。短いキー入力の取りこぼしを修正。子狐の通常歩行・走り・伏せ歩き各5視点×4コマを左右反転も使って8方向に表示 | macOS の画面で向きによる画像の変化を確認。操作感とアニメーション品質は継続評価 |
| macOS ビルド | `make -C game bundle` で `.app` を作成 | 署名・公証を伴う公開用パッケージは未作成 |
| Windows ビルド | CMake と CI の設定を追加 | Windows 実機と CI 上の結果は未検証 |

現時点の成果物は**遊べる 2.5D 実装試作**です。通常歩行・走り・伏せ歩きの視点別4コマは実装済みですが、Blender 由来の立体表現、公開中継の運用条件、初見プレイ評価はまだ完成していません。[設計文書一覧](document-index.md) にある「草案」は、これらの実装が完成したという意味ではありません。
