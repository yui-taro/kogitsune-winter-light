# 『こぎつねと冬の灯り』美術・音・画面方針書

版: 0.2／2026-10-04  
状態: **レビュー用草案。完成画面の見た目と音の基準、およびその評価方法を定義する。画像生成・モデル制作・音素材制作の開始指示ではない。**

本書は[要件定義書](requirements.md)の品質要件（E-02、E-05、P-03、P-04、N-01、N-05、N-09）を、美術と音の判断基準にしたもの。遊びのルールは[ゲーム設計書](game-design.md)、場面と構図は[物語・レベル設計書](story-and-levels.md)、造形の根拠は[子狐と狛犬の造形調査](../research/production/character-art.md)、描画の制約は[描画工程調査](../research/production/rendering-pipeline.md)に従う。

**画風は「立体のある絵本映画」に決定**（D-11、[V-01の比較結果](v-01-prompts.md)）。カメラの詳細と描画方式は未決定。本書の読みやすさ、光の使い方、音の役割は、採用画風での制作と評価に適用する。

## 1. 見た目の目標と優先順位

**一文で:** 青い吹雪の夜に、金色の灯りが一つだけ灯っている。その灯りを、小さな子狐が守り手から持ち帰ろうとしている。守り手は神社では石の狛犬、持ち場を離れると生きた山犬になる。この関係が通常のプレイ画面で分かること。

画面の中で目に入る順番を、次のように固定する。細部の描き込みより、この順番を優先する。

| 順位 | 対象 | 読ませたいこと | 主な手段 |
| --- | --- | --- | --- |
| 1 | **子狐** | 自分がどこにいて、どちらを向き、何をしているか | 暖色の体、大きな耳と尾の輪郭、動き |
| 2 | **狛犬** | どこを見て、何に気付き、次にどう動きそうか | 体の向き、耳、目の光、足音 |
| 3 | **灯籠** | 目標の場所。盗んだ後は狐と一緒に動く危険 | 画面で唯一の暖かい光源 |
| 4 | **手掛かり** | 足跡、鈴、遮蔽物、抜け道 | 雪面の陰影、揺れ、形の差 |
| 5 | **背景** | 場所と季節、物語の雰囲気 | 低い明暗差、吹雪、遠景の稜線 |
| 別枠 | **右下のHUD** | 狐にできる四つの行動 | 定位置、形、色以外の印 |

背景が4位以上より目立った場合は、背景の描き込みや明暗差を減らす。

## 2. 採用画風と比較結果（D-11）

V-01では、同じ構図（雪の境内で狐が灯籠に近づき、狛犬が守る）を、次の3方向で比較した。**採用はA「立体のある絵本映画」**。採用画像は[こちら](v-01/a-storybook-3d.png)。

| 候補 | 特徴 | 期待できること | 心配な点 |
| --- | --- | --- | --- |
| **A. 立体のある絵本映画（採用）** | 3Dの量感と柔らかい光。形を単純化し、穏やかな色面で描く | 子狐の愛らしさと、雪・灯りの雰囲気の両立。[画面案](../research/fox-visual-implementation.md)の第一候補 | よくある見た目になりやすい。独自の印象を作る工夫が必要 |
| **B. 木彫りと和紙の舞台** | 木彫り・石彫りと、重ねた和紙の立体ジオラマ | 手仕事の質感と神社の世界観 | 素材感が細かくなりすぎると画面の情報が散る |
| **C. 明快なセル調3D** | 大きな色面と少数の影階調で形を示す | 小さな画面で形と進路を読み取りやすい | 陰影の単純化で雪夜の柔らかさが薄れる可能性 |

**V-02以降の確認基準（すべて実際のゲーム画面サイズで見る）:**

1. 1秒見ただけで、子狐・狛犬・灯籠を指せる（7章の縮小試験）。
2. 子狐を「守りたい」と感じる（E-02）。
3. 雪・灯り・神社・キャラクターが一つの世界に見える（E-05）。
4. 盗難後に、灯籠の光が動いても破綻しない見込みがある（[描画工程](../research/production/rendering-pipeline.md)のゲート3）。
5. 2Dで合成する場合も、リアルタイム3Dに変える場合も、同じ方向性を保てる。

V-02は画風、光、狐と灯籠の大きさ、神社の空間の参照とする。**V-02に描かれた石のまま歩く狛犬の造形は新設定に採用しない。** 守り手の二形態は[新C-05プロンプト](c-05-transformation-prompt.md)で改めて決める（N-09）。

## 3. 色と光の規則

画風に関係なく、次の規則を守る。具体的な色の値は、V-02で決めて本書に追記する。

### 色の役割

| 色の役割 | 使う場所 | 意味 |
| --- | --- | --- |
| **深い青・青灰** | 夜の空気、雪の影、巣の冒頭 | 寒さ、危険、静けさ |
| **青白** | 雪面、吹雪 | 地面と痕跡の舞台。手掛かりが読める明るさを保つ |
| **朱** | 鳥居、社 | 神社の場所と境界。光源にしない |
| **金・橙** | 灯籠の光、狛犬のひびの奥の光、終章の巣の火 | 暖かさ、目標、命。**画面で光る暖色はこれだけ** |
| **子狐の赤茶** | 子狐、弟妹 | 主役。雪の青と補色の関係で目立たせる |
| **赤い布** | 巣の入口 | 帰る場所の目印。朱の鳥居と区別できる、くすんだ赤にする |
| **石の灰・苔の緑** | 定位置の狛犬、台座 | 重さと古さ。雪をかぶって背景になじみつつ、輪郭は残す |
| **雪灰・暗い灰** | 動物姿の山犬 | 赤茶の子狐と分かれ、青い雪夜でも頭と脚の向きが読める |

- **暖色の光源は灯籠一つにする。** 境内に石灯籠や窓明かりなど、他の暖かい光を置かない（[レベル設計 2章](story-and-levels.md)）。石像のひびと山犬の目の光は灯籠より小さく暗くし、変身の光も第二の光源にしない。
- **子狐の赤茶と灯籠の金を混ぜない。** 灯籠をくわえた時も、顔と灯籠の明るさに差をつけ、顔が光に埋もれないようにする。
- **朱の鳥居と子狐の色を近づけすぎない。** 鳥居の前を通る時に輪郭が消えないかを確認する。

### 場面ごとの光

| 場面 | 主な光 | 印象 |
| --- | --- | --- |
| S0 巣 | 雪明かりのみ。遠くに神社の点の光 | 寒さと遠い希望 |
| S1 森・高台 | 雪明かりと、木の間から見える神社の光 | 静かな夜。高台で巣と神社の光の位置関係を見せる |
| S2・S3 神社（盗む前） | 台座の灯籠が境内を照らす。鳥居の影 | 守られた暖かさ |
| S3 盗難の瞬間 | 台座が暗くなり、光が子狐と一緒に動く | 達成と不安 |
| S4 帰り道 | 子狐の周りだけ暖かい。吹雪で暗い | 光が自分を目立たせる緊張 |
| S5 終章 | 巣の火の橙 → 夜明けの淡い光 | 安堵。神社と巣の両方に灯り |

## 4. 造形の基準

### 子狐（C-01〜C-03）

[造形調査](../research/production/character-art.md)の初稿を採用する。これらは仮説であり、実画面で評価して修正する。

| 部位 | 基準 |
| --- | --- |
| 全体 | 小さな胴、大きめの頭、短めの脚、大きな尾。重心は低い |
| 顔 | 額を広く、頬を柔らかく、目は斜め見下ろしでも読める大きさ。**口吻（鼻先）は短くしすぎず、キツネらしさを残す** |
| 耳 | 立った三角形を保つ。耳の向きを、警戒・安心・迷いを伝える主な手段にする |
| 尾 | まず大きな一塊の輪郭を作り、毛束は後から加える。走りと足跡を払う動作の向きが読めること |
| 色 | 暖色の体、明るい顎と胸、暗い脚先。雪・鳥居・灯りと混ざらない明るさの差 |
| 毛 | 細い毛を多くするより、大中小の毛束で輪郭を作る。通常画面で毛先がちらつかない |

**弟妹（C-04）:** 子狐と同じ狐の基本構造を使い、頬と体を丸く、口吻と脚を短くして幼さを出す。主人公の明るい橙赤に対し、Aは濃い栗色と白い額印、Bは淡い杏色と広い暗色の耳先で見分ける。二匹の動きは小さくする。

### 守り手の狛犬／山犬（C-05、C-06）

| 部位 | 基準 |
| --- | --- |
| 同一性 | 定位置の石の狛犬と、持ち場を離れる時の生きた山犬は同じ一体。同じ頭・胴・脚・尾の比率と、耳の欠け・胸の印など少数の共通特徴を持つ |
| 石の姿 | 神社の低い定位置に伏せる簡潔な石彫り。少量の雪と苔、控えめなひび。豪華な渦巻きのたてがみ、巨大な巻き尾、怒った眉を避ける |
| 動物の姿 | 子狐よりはっきり大きい雪灰色の山犬。重さを残しつつ歩ける四肢と大きな前足。暗い脚で狐と色・輪郭を区別する |
| 顔と動き | 穏やかさと警戒心が両立する。耳、目線、首、前足、姿勢で観察・追跡・ためらいを見せる |
| 変化 | 耳と目線、肩の雪落ち、踏み出す前足の順に石肌が毛へ移る。同じ体が変わり、石の殻から別個体が出てこない |
| 帰還 | 役目が落ち着き定位置に戻った時だけ石になる。結末では火を分けて灯籠を戻した後に石へ戻る |
| 目の光 | 視線の向きを知らせる小さな手掛かり。灯籠より弱く、第二の光源にしない |

### 灯籠と小道具（P-01、P-02）

| 対象 | 基準 |
| --- | --- |
| 灯籠 | 子狐がくわえられる取っ手と、狛犬の前足で開けられる蓋。子狐と並べた時の大きさを設定画で決める。点灯と消灯で形を変えない |
| 台座 | 灯籠がない時に「空いている」と一目で分かる形 |
| 鈴 | 鳥居に下がる。鳴った時に揺れと雪落ちが見える大きさ |
| 倒木 | 子狐が伏せれば通れ、狛犬は通れないと見て分かる高さ |
| 赤い布 | 遠くからも見える、巣の目印 |
| 足跡 | 子狐の足跡と、S1の野うさぎの足跡を形で区別できる |

## 5. 動きと演技

狛犬の判断をプレイヤーが読めることが最優先（A-04）。**どの行動意図にも、動き出す前の予兆**を用意する。

| 狛犬の状態・意図 | 予兆 | 動作 | 音 |
| --- | --- | --- | --- |
| 持ち場で見張る | — | 石のまま小さく耳と首を動かし、ときどき灯籠を見る | 静か。ときどき石のきしみ |
| 何かを聞いた | 耳が音の方へ向く | 首が向き、体はまだ動かない | — |
| 門を守ると決めた | 音の方を見た後、灯籠を見直す | 台座の前に座り直す | 重い着地音 |
| 鈴・足跡を調べると決めた | 体が調べる先へ向き、石肌が毛へ変わる | 山犬となって歩き出す。足跡は前足で雪を払って確かめる | 雪が落ちる小さな音から、雪を踏む足音へ移る |
| 空振りした | 調べた場所で止まる | 鼻を鳴らし、周りを見回して定位置へ戻る。役目が落ち着けば石になる | 短い息、帰還後に静けさ |
| 狐を見つけた | 目の光が強まり、身構える | 低い姿勢で前へ進む（即座の捕獲にはしない） | 足音が速くなる |
| 盗難を知った | 空の台座の前で止まる | 出口と光の方向を見比べる | 鎖の音が止む |
| 巣でためらう（S5） | 足音が止まる | 体を低くし、伸ばした前足を一度止める | 風だけ |

**子狐の演技**は[造形調査](../research/production/character-art.md)の表に従う。待機中の呼吸、忍び足の前の小さなため、灯籠の重さで首が下がる様子などで、愛らしさと必死さを見せる。狛犬に気付いた時は、耳 → 目 → 尾の順に反応し、体は遅れて向く。

**作る量の上限:** 方向別のアニメーションは、まず4方向で、待機・歩き・伏せから作る。動く光の検証（[描画工程](../research/production/rendering-pipeline.md)のゲート3）を通るまで、方向や動作を増やさない。

## 6. 通常画面と近景

### 通常のプレイ画面

| 項目 | 方針 |
| --- | --- |
| カメラ | 固定の斜め見下ろし。プレイヤーは回転できない。場面内は平行移動だけで追う（[レベル設計](story-and-levels.md)） |
| 評価に使う画面 | 1920×1080を評価用の基準とする。完成版の解像度と対応する画面比は未決定（N-08）。16:10と小さめのウィンドウでも確認する |
| 配置 | 重要な物は画面の中央からやや左。右下はHUD用に空ける |
| キャラクターの大きさ | 子狐はV-02を参照する。守り手は新C-05で二形態の比率を決め、石像の耳と山犬の頭の向きが読めることを最低条件とする |
| 前後関係 | 鳥居、杉、倒木は手前と奥に分け、キャラクターがその前後を通れることを見せる |
| 吹雪 | 画面の手前と奥に分ける。キャラクターと手掛かりを覆い隠すほど濃くしない |

通常画面では見えにくい表情と質感を、同じモデルを使った別カメラの短い場面で見せる。

| 場面 | 見せること |
| --- | --- |
| S0 冒頭 | 震える弟妹、火のつかない小枝、子狐が神社の灯りを見上げる |
| S2 狛犬の初登場 | 雪をかぶった石の顔と慎重な目。持ち場を離れる判断をした時、同じ一体が山犬へ変わる予兆 |

## 7. 手掛かりの見せ方

色だけに頼らず、**形・動き・音の少なくとも二つ**で伝える（N-05）。

| 手掛かり | 形・明るさ | 動き | 音 |
| --- | --- | --- | --- |
| 新しい足跡 | くっきりした輪郭と深い影 | — | 踏んだ時の雪の音 |
| 古い足跡 | 輪郭がぼけ、影が浅い | 風で少しずつ薄れる | — |
| 払った跡 | 雪面がならされ、跡が消える | 尾の動きと同時に雪が舞う | 柔らかい払う音 |
| 鈴 | — | 揺れと雪落ち | 鈴の音 |
| 狛犬の視線 | 目の光の向き | 首と耳の向き | — |
| 灯籠の光 | 光の範囲が地面に見える | 狐と一緒に動く | 小さな火のゆらぎ音 |
| 隠れられる場所 | 遮蔽物の形で分かる。必要なら控えめな印を検討 | — | — |

狛犬の視界を円錐などの図形で常に表示するかは、`ui-and-controls.md`と試遊で決める。本書では、**演技だけで視線が読めること**を先に目指す。

## 8. 音の方針

物語は原則として無言。音は、雰囲気よりも**手掛かりとしての役割**を先に決める。

| 音 | 役割 | 区別のしかた | 対になる視覚の手掛かり |
| --- | --- | --- | --- |
| 子狐の足音（歩く） | 自分の音の大きさを知る | 軽く小さい | 雪に残る足跡 |
| 子狐の足音（走る） | 音が大きくなった危険 | 速く大きい | 深い足跡、雪しぶき |
| 子狐の足音（伏せる） | 静かに動けている | ほとんど聞こえない | 低い姿勢 |
| 狛犬の足音 | 狛犬の位置と速さ | 重い石の音。速さで警戒度が分かる | 狛犬の動き |
| 鈴 | 囮、最初のJev場面のきっかけ | 澄んだ高い音。方向が分かる | 揺れと雪落ち |
| 風・吹雪 | 寒さと時間の流れ。強まる時が復路 | 環境音。手掛かりの音を消さない音量 | 吹雪の濃さ |
| 鎖の音 | 盗む瞬間の静けさ | 音楽が止まった中で響く | 台座が暗くなる |
| 火のゆらぎ | 灯籠が近くにある | 小さく暖かい音 | 光の範囲 |
| 火が移る音 | 結末の安堵 | 小さな着火音 | 小枝に火が灯る |

**音楽:** 狛犬の気付きを音楽の切り替えだけで伝えない。警戒は足音と演技で伝え、音楽は場面の感情を支える程度にする。盗む瞬間は音楽を止める。

**音量の優先順位:** 鈴・狛犬の足音 ＞ 子狐の足音 ＞ 火 ＞ 風 ＞ 音楽。手掛かりになる音が、環境音や音楽に埋もれないようにする。

**左右の定位:** 鈴と狛犬の足音は、画面上の位置に合わせて左右に振る。ただし、左右が聞き取れなくても視覚の手掛かりで分かるようにする。

## 9. 右下のHUDの見た目

挙動は`ui-and-controls.md`で決める。本書では見た目だけを定める。

- 四つのボタン（伏せる／走る／尾で払う／触れる）は、木彫りのお守りのような輪郭にする。背景を大きく隠す不透明なパネルは使わない。
- 使えるか使えないかを、**色と、形または印の両方**で区別する。例: 使える時は縁が明るい、使えない時は灰色に斜線。
- アイコンは、画面上の子狐と同じ造形にそろえる（U-02）。小さな表示でも四つが区別できること。
- 「触れる」の内容が変わる時（鳴らす／くわえる／置く）は、アイコンの一部を変え、ボタンの位置は変えない。
- 画像生成で作った検討用のボタン画像は、そのまま素材にしない（[画像一覧](image-reference-list.md)の方針）。

## 10. 参考資料と出典の記録

- 参考画像は`art/references/`に置き、**出典、取得日、利用条件**を一緒に記録する。このフォルダは、画像を集める段階になってから作る。
- 実在する神社・狛犬の写真は、造形と質感の参考に使う。特定の作品の絵柄やキャラクターを、そのまま写したり、画像生成でまねさせたりしない。
- 画像生成を使う時は、[画像一覧](image-reference-list.md)の記録項目（採用版、生成時の指示、参照した基準画像、モデル化で確定した形、残った矛盾）を残す。
- 音素材も、自作か利用条件を確認したものに限り、出典と条件を記録する。GitHubで公開する範囲（D-13、N-10）は`release-and-operations.md`で決める。
- 画風の参考画像として[V-01のA案](v-01/a-storybook-3d.png)を採用した。これは画風の基準であり、最終構図やモデル寸法の基準はV-02で定める。以前に作った神社の画像1枚は検討用で、基準には使わない。音素材は未採用。

## 11. 評価の方法（完成の目安）

実際の表示サイズの見本を使い、次の試験で評価する。人数と合格ラインは`verification.md`で決める。少人数の身内の印象だけで合格としない。

| 試験 | 方法 | 対応要件 |
| --- | --- | --- |
| **縮小試験** | 通常画面の静止画を1秒見せ、子狐・守り手・盗む対象を指してもらう | E-02、N-01 |
| **明暗・輪郭試験** | 暗い雪と明るい雪の両方の上で、子狐の耳と尾、狛犬の頭の向きが読めるか | P-03 |
| **白黒試験** | 画面を白黒にして、灯籠・足跡・使えないボタンが区別できるか | N-05 |
| **動作試験** | 音とHUDを隠した10秒動画で、伏せる／走る／足跡を消す／灯籠を運ぶを区別できるか | F-01、P-03 |
| **予兆試験** | 狛犬が動き出す直前で止め、「次にどこへ行くか」を予想してもらう | A-04、E-03 |
| **音の試験** | 画面を見せずに鈴・狛犬の足音・子狐の走る音を聞き分けられるか。逆に、音なしでも重要な出来事が分かるか | P-04、N-05 |
| **光の一致試験** | 灯籠を運ぶ動画で、狐・雪・石が同じ空間で照らされて見えるか | E-05、[描画工程のゲート3](../research/production/rendering-pipeline.md) |
| **感情試験** | S0冒頭とS5結末を無言で見せ、何が起きたか説明してもらう | E-01、P-05 |
| **一貫性の確認** | 設定画と3Dモデルで、比率・色・特徴がずれていないか | N-09 |

## 12. 本書で保留すること

| 保留項目 | 決める時期・文書 |
| --- | --- |
| 採用画風の基準ゲーム画面、具体的な色の値、子狐の画面上の大きさ | V-02の作成時 |
| 完成版の解像度、対応する画面比、性能目標 | `basic-design.md`、`technical-and-assets.md`（N-08） |
| 2.5D合成か、リアルタイム3Dか | 描画工程のゲート3の結果（`basic-design.md`） |
| 狛犬の視界をHUDで表示するか、近景をスキップできるか | `ui-and-controls.md` |
| 音楽の曲数と作り方 | 本書の改訂時 |
| 公開する素材とライセンス | `release-and-operations.md`（D-13） |

**画像一覧への追加候補:** [レベル設計書](story-and-levels.md)で必要になった、高台の遠景、社の床下、夜明けの高台。画像一覧を改訂する時に加える。

## 13. レビューで見てほしいこと

1. 画面で目に入る順番（子狐 → 狛犬 → 灯籠 → 手掛かり → 背景）でよいか。
2. 「暖色の光源は灯籠一つ」という規則は、表現を縛りすぎていないか。
3. 採用した絵本映画調を、通常のゲーム画面と動く灯籠の光でも保てるか。
4. 狛犬の各行動に、プレイヤーが読める予兆があるか。
5. 音の役割が、音を聞けない場合の視覚の手掛かりと対になっているか。
