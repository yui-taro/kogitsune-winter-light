# 子狐を愛らしく、狛犬を記憶に残る存在にする

## 調査から採る原則

大きめの頭と目、丸い顔、高めの額、小さめの鼻や口は、人間の乳児の顔について「かわいさ」と養育への動機の評価に結び付いた。[Glockerらの実験](https://pubmed.ncbi.nlm.nih.gov/22267884/)。犬・猫と人間の顔を使った児童研究でも、乳児的な顔の特徴はかわいさの判断と視線配分に影響した。[Borgiらの論文](https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2014.00411/full)。**キツネの3Dキャラクターやゲーム画面で同じ効果量が出る証拠ではない。** 子狐の造形仮説として使い、実画面で評価する。

キツネとして読める形は、尖った鼻先・立った耳・大きく豊かな尾。[Animal Diversity Webのアカギツネ資料](https://animaldiversity.org/accounts/Vulpes_vulpes/)。頭を丸くしても、耳と口吻と尾を全部丸めると別の動物に見える。顔だけは幼く、外形にはキツネの特徴を残す。

## 子狐の造形仕様（初稿。実測値ではない）

| 部位 | 初稿の意図 | 実画面で見ること |
| --- | --- | --- |
| 全体 | 小さな胴体、大きめの頭、短めの脚、大きな尾。重心は低い | 暗い雪上で「子狐」と一瞬で分かるか |
| 顔 | 眉上を広く、頬を柔らかく、目を読める大きさに。口吻は短くしすぎない | 斜め見下ろしでも目と鼻先が区別できるか |
| 耳 | 立った三角形を残し、先端と付け根で表情をつける | 耳だけで警戒・安心・迷いが読めるか |
| 尾 | 一塊の大きな輪郭を先に作り、毛束を後から足す | 走り・足跡を払う動作の方向が読めるか |
| 色 | 暖色の体、明るい顎・胸、暗い脚先。灯籠をくわえても顔が埋まらない明度差 | 雪、鳥居、金色の光と混ざらないか |
| 毛 | 細い一本一本より大中小の毛束で外形を作る | 通常プレイ解像度で毛先がノイズにならないか |

**制作順:** 無彩色の横・正面・斜めシルエット3案 → 実際のゲーム画面サイズに縮小して比較 → 1案を粗い3Dモデルへ → 顔と耳・尾の可動域を確認 → 毛束と材質 → ライティング → アニメーション。コミュニティ製の[character-image-to-3d skill](https://github.com/laxmimerit/Claude-Skills/blob/main/character-image-to-3d/SKILL.md)も参照画像の分解、シルエット優先、段階的な構築を推奨するが、これは実装手順の参考であり造形の科学的根拠ではない。

## 動きで愛らしさを作る

| 動き | 子狐の演技 | ゲームで伝える状態 |
| --- | --- | --- |
| 待機 | 呼吸で肩と尾がごく小さく動く。ときどき耳が風や鈴へ向く | 生きている・何かを聞いた |
| 忍び足 | 頭は低く、足を置く直前に一瞬ためる。尾は体の後ろで静か | 隠れる意思がある |
| 走る | 小さな跳ねを入れるが、接地タイミングは明確 | 音と足跡が増える |
| 尾で払う | 尾が雪面を横切り、消える足跡と同時に雪が舞う | 効果が起きた |
| 灯籠をくわえる | 重さで首が下がり、体が少し沈む。顔の表情が隠れない位置で保持 | 大切な物を運んでいる |
| 狛犬に気付く | 耳・目・尾の順に反応し、体が遅れて向く | 危険を理解した |

「かわいい」は静止画の顔だけでは決まらない。行動のためらい、重さ、弟妹へ急ぐ意志を、小さな体の演技で見せる。通常画面では顔の細部が小さくなるため、耳・尾・姿勢を主要な感情チャネルにする。見せ場の近景は同じモデルを別カメラでレンダーする。毛を細く増やすより、輪郭と動作の明瞭さを先に見る。Pixarの教材にもキャラクターモデリング、リギング、毛のシミュレーションと造形例がある。[モデリング](https://www.khanacademy.org/computing/pixar/modeling-character)、[リギング](https://www.khanacademy.org/computing/pixar/pixar-rigging)、[毛の事例](https://www.khanacademy.org/computing/pixar/simulation/hair-simulation-101/v/video5-launch)。

## 狛犬の対比

狛犬は子狐より大きく、石の重さがある。しかし恐怖一辺倒にしない。肩・脚は角ばった彫刻、耳と目だけ少し可動。警戒時は低い姿勢と強い前進、迷いは足を止めて灯籠と狐を見比べる、優しさは体を横へずらして道を空ける。**Jevが選んだ意図を見た目で読めること**をアニメーションの要件にする。

## 造形レビューの条件

1. **縮小試験:** 通常のゲーム画面へ置いた1秒の静止画で、未説明の人が子狐・守り手・盗む対象を指せる。
2. **輪郭試験:** 暗い背景と明るい背景の両方で、狐の耳・尾、狛犬の脚・頭の方向が読める。
3. **動作試験:** 音声とHUDを隠した10秒動画で「伏せる／走る／足跡を消す／灯籠を運ぶ」が区別できる。
4. **感情試験:** 子狐が弟妹を見る、狛犬がためらう場面を無言で見せ、第三者に何が起きたか説明してもらう。正答率は目標を後で設定し、少数の身内だけの印象で合格としない。
5. **技術試験:** すべての方向で足元ピボット、尾の接地、毛先の透過縁を確認する。

造形の良し悪しは外部資料から確定できない。反復的な実画面レビューを制作工程に組み込む。
