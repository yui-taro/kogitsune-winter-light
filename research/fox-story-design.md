# 『こぎつねと冬の灯り』ストーリー設計書

版: 0.1／2026-10-03。**物語・演出の提案**であり、Jevの挙動やプレイ時間を実測した結果ではない。

**現行要件との関係:** 以下の20～30分という総時間と場面ごとの分数は、この版を作った時点の仮案。現在は[要件定義書](../design/requirements.md)で、**開始後5～10分以内に狛犬のJev判断が映える最初の場面を置く**ことを確定し、総プレイ時間は未決定としている。後続のゲーム設計では現行要件を優先する。

## 1. 作品の核

**ログライン:** 吹雪で巣が壊れ、弟妹が凍える夜。子狐は山の神社から消えない灯りを盗み、狛犬の追跡をかわして巣へ持ち帰る。狛犬は山道を照らす灯りを守る役目と、目の前の小さな命を助けたい気持ちの間で揺れる。

**プレイヤーが理解する目標:** 「灯籠を取る → 巣へ運ぶ」。冒頭30秒で、震える弟妹、燃えない小枝の山、山の上の灯籠を順に見せる。文章による世界設定の説明は置かない。

**物語の問い:** 灯りを守る狛犬は、灯りを盗んだ子狐をどう扱うか。子狐は狛犬を倒さず、嘘の足跡や音でかわして進む。

**想定:** 一人用の短編ステルスアドベンチャー。初回20～30分、再挑戦では10～15分程度を目標とする。画面は斜め見下ろしの固定カメラを基本とし、会話はほぼ使わず、動き・視線・音・光で伝える。数字は制作目標であり検証前。

## 2. 世界のルール

| ルール | 物語と遊びへの意味 |
| --- | --- |
| 山には冬の夜でも消えない小さな灯籠が一つある。神社の門に掛けられ、吹雪の山道を照らす。 | 狛犬が離れずに守る理由がある。盗むと神社と道が暗くなる。 |
| 灯籠の火はほかの薪に分けても消えない。灯籠の蓋を開けるには人の手か狛犬の大きな前足が要る。 | 子狐は灯籠を運ぶしかない。結末で火を分け、灯籠を戻せる。 |
| 子狐の巣は吹雪で覆いが壊れ、すきま風が入る。巣には集めた小枝があるが、火をつけられない。 | 盗む動機と、最後に火を分ける行動が視覚でつながる。 |
| 子狐は神社の言葉を話せず、狛犬も狐の目的を知らない。 | 狛犬を説得する説明会話ではなく、行動と目撃で理解が進む。 |
| 雪には足跡が残る。風で古い跡は薄れ、尾で近くの跡を消せる。灯籠は暗闇で目立つ。 | 行きは痕跡、帰りは光が主な緊張を作る。 |

夜明けは物語上の目安。弟妹の死を示すカウントダウンは置かず、吹雪の強まりと呼吸・身を寄せる動きで急ぐ理由を見せる。捕まった時は灯籠を社に戻され、近い場所から再挑戦できる。失敗で家族が死ぬ場面は作らない。

## 3. 登場人物

### 子狐（プレイヤー）

- **望み:** 弟妹を温める。灯籠そのものを所有したいわけではない。
- **できること:** 低い穴をくぐる、雪に足跡を残す・尾で消す、鈴や枝で音を作る、灯籠の取っ手を口にくわえる。
- **できないこと:** 狛犬との直接対決、蓋を開けて火を移すこと。灯籠を運ぶ間は口を使う工作が制限される。
- **感情の線:** 不安 → ひらめき → 盗む罪悪感と追跡の恐怖 → 家族の安堵 → 狛犬への警戒が信頼に変わる。

### 狛犬（Jevで判断する守護者）

- **望み:** 灯籠を門に戻し、山道を安全に保つ。
- **性格:** 任務に忠実で慎重。小さな動物に乱暴をしたくない。鈴の音だけで門を空けるような短気さはないが、十分な手掛かりが重なると確かめに行く。
- **知識の限界:** 最初は狐の巣も弟妹も知らない。見た足跡、聞いた音、見えた光、灯籠の有無、自分が以前に調べた場所だけを覚える。
- **感情の線:** 静かな警戒 → 侵入への苛立ち → 灯籠を奪われた責任感 → 巣を見て迷う → 火を分ける決断。
- **見た目と演技:** 石の体に雪が積もり、動くとひびの奥に小さな橙の光が見える。疑う時は耳と視線だけを動かし、追跡時は重い足音を立てる。巣では足音が止まり、体を低くする。

### 弟妹

巣で身を寄せる二匹。言葉を話さず、呼吸、震え、子狐に近寄る仕草で状態を示す。プレイヤーが帰る対象として常に記憶に残るよう、巣の入口に同じ赤い布切れを置く。布は吹雪の森でも帰り道の目印になる。

### 白い梟

遠景と音の演出にとどめる。初版では狛犬への通報役や二体目のAIにしない。物語の主軸とモデル制作を子狐・狛犬・弟妹に集中する。

## 4. 舞台と導線

```text
巣 ── 杉の森 ── 赤い鳥居／鈴 ── 境内／狛犬 ── 門の灯籠
          └─ 低い倒木の抜け道 ──────┘
```

往路と復路で同じ場所を使う。往路は暗く、木陰と足跡が重要。復路は灯籠をくわえるため子狐の周囲だけ明るくなり、同じ道の隠れ場所と危険が変わる。杉の森の高台から巣の赤い布と神社の灯りの両方が見える構図を一つ作り、物語上の距離感を示す。

## 5. 場面ごとの進行

| 場面 | プレイヤーが見ること・すること | 感情／見せる情報 | 狛犬の役割 |
| --- | --- | --- | --- |
| **序章: 壊れた巣**（約2分） | 吹雪が巣の覆いをはがす。弟妹が震え、子狐が集めた小枝も冷たいまま。遠くの神社だけが暖かく光る。操作で巣から出る。 | 目的と家族への愛着。文字説明は最小限。 | 登場しない。 |
| **第一場: 杉の森**（約3～5分） | 歩く、走る、伏せる、足跡を消す操作を覚える。遠くに狛犬が動く影が見える。 | 雪が自分の行動を記録することを学ぶ。 | 遠景で門を見回し、慎重な性格を先に見せる。 |
| **第二場: 鳥居と鈴**（約4～6分） | 鈴を鳴らす、足跡をわざと残す、倒木をくぐるなどして境内への入口を探す。 | 狛犬は音に必ず飛びつくわけではない、と分かる。 | 足跡・鈴・灯籠のどれを優先するかを状況に応じて選ぶ。 |
| **第三場: 灯籠を盗む**（約4～6分） | 台座に近づいて灯籠の取っ手をくわえる。門の光が消え、風の音と狛犬の足音が強くなる。 | 盗みの達成と「道を暗くした」不安が同時に来る。 | 盗難を発見したら追跡・出口警戒・周辺確認から選ぶ。 |
| **第四場: 光る帰り道**（約5～8分） | 灯籠の光で隠れにくい。往路と違う抜け道や吹雪の遮蔽を使って巣へ戻る。 | 持ち帰る行為そのものが難題になる。 | 自分が確認した手掛かりから捜索先を選ぶ。知らない巣へ瞬間移動しない。 |
| **終章: 灯りを分ける**（約2～3分） | 灯籠を弟妹のそばに置く。暖まるが、神社の門は暗い。狛犬が灯籠の光をたどって到着し、小枝と弟妹を見て立ち止まる。蓋を開けて小枝に火を分け、灯籠を門へ持ち帰る。 | 子狐の目的と狛犬の役目が両立する。翌朝、門と巣の両方に灯りがある。 | 最終的な救助は物語上の確定場面。到着の仕方と警戒・ためらいの演技に、それまでの判断履歴を反映する。 |

表の時間は目標値。通しプレイで長過ぎる場合は森の往路を削り、鳥居・境内・復路を残す。

## 6. 重要場面の演出と操作

**冒頭:** 固定カメラで巣の割れ目に雪が吹き込み、弟妹が子狐の尾の下に潜る。子狐が乾いた小枝を鼻で寄せるが火はつかない。カメラが狐の視線に沿って山の灯籠へ上がる。画面の目標表示は「灯りを持って帰ろう」程度にする。

**初めて狛犬を見る場面:** 足跡を見つけた狛犬はすぐ走らず、前足で雪を払って跡の向きを確かめる。子狐が隠れる時間を与え、「慎重な守り手」として読めるようにする。視線、耳、石の足音はJevの行動選択前に共通の予兆として使う。

**盗む瞬間:** 台座の灯籠が消え、鳥居の影が広がる。音楽を止め、風と鎖の音だけにする。狛犬がどこにいるかは、そのプレイでの判断結果のまま。必ず同じ方向から飛び出す演出にはしない。

**結末:** 狛犬が巣に着いた時、子狐は弟妹の前に立つ。狛犬は灯籠、小枝、弟妹を順に見る。伸ばした前足を一度止め、狐に危害を加えず蓋を開く。薪に火が移ると弟妹が近づく。狛犬は灯籠をくわえて門に戻り、子狐は巣の中からその背中を見る。無言で性格の変化を伝える。

## 7. 分岐と失敗の扱い

- **物語の結末は一つ:** 家族が暖まり、灯籠は神社へ戻る。狛犬の慈悲をJevの偶然の一回の出力に委ねず、巣で事情を目撃した後の結末として固定する。
- **道中は変わる:** 狛犬が足跡を追ったか、鈴を疑ったか、出口を守ったかで、通りやすい道と追跡の距離が変わる。子狐が何度も同じ囮を使った履歴は、狛犬がゲーム内で実際に経験した時だけ反映する。
- **終章の演技差:** 狛犬が子狐を早くから目撃していた場合は荒い足取りで追いつく。ほとんど見失っていた場合は、灯籠の光を遠くから見つけて静かに到着する。どちらも巣で弟妹を見る場面につながる。
- **捕まった場合:** 灯籠を戻され、直近の安全な地点から再開する。子狐が死ぬ、家族が死ぬ、取り返しのつかない分岐は設けない。発見の原因は足跡・音・光・視界で説明できるようにする。

## 8. Jevが担う部分と物語の保護

Jevへの入力は狛犬の**固定した性格**、その時点の**観測**、実際に経験した**短い記憶**だけ。候補は場面に応じて `門を守る／足跡を調べる／鈴の音を調べる／出口へ回る` などから合法なものだけを渡す。[公式のChoice](https://docs.typesafe.ai/primitives/choice)は定義済みの候補から回答を返す。複雑な物語の生成、台詞、長い計画は[既知の弱点](https://docs.typesafe.ai/model-jaggedness/jev-1.13)を踏まえてJevに任せない。[Heist One](https://github.com/AbdelStark/heist-one)は警備判断とゲーム世界を分ける先例だが、本作での面白さは未検証。

| 守る設計 | 理由 |
| --- | --- |
| 狛犬が見ていない狐の現在地や巣の場所を入力しない | 情報の不公平を防ぐ。 |
| 重要な場面の発生条件と結末はゲームコードで決める | APIの遅延や意外な判断で物語が破綻しない。 |
| Jevの行動が変わる前に、耳・視線・姿勢で兆候を見せる | プレイヤーが理由を推測して対策できる。 |
| 通信が遅い時は狛犬が直前の行動を短時間続ける | ゲームと演技を止めない。 |
| プレイ後に狛犬の目撃情報と行動を時系列で見られる | 「AIだから動いた」ではなく「この足跡を見て判断した」と伝える。 |

Jevの性格反映は仕様で保証された機能ではなく、状態の与え方を使った本作の設計仮説。[公式State](https://docs.typesafe.ai/concepts/state)は関連する情報を構造化して渡せる。固定ルール版と同じ場面を比較し、判断の一貫性、意外だが納得できる反応、プレイヤーの理解を試す。

## 9. 美術・音の方針

- **色:** 巣は暗い青、神社は朱色と金、帰還後の巣は柔らかな橙。プレイヤーの目的地と感情の変化を色で追えるようにする。
- **モデル:** 子狐の耳と大きな尾を遠景でも読める形にする。雪が毛先に積もる。狛犬は石と苔の質感、止まる・振り向く・屈む動きに注力する。弟妹は同じ基本リグを小さく変えて制作負荷を抑える。
- **画面:** 境内は灯籠を中心に置き、鳥居と倒木で隠れ道を作る。広い山全体を作らず、背景の稜線と吹雪で奥行きを出す。
- **音:** 雪を踏む軽い音、石の重い足音、鈴、風、火が移る小さな音を識別しやすく作る。狛犬の気付きはBGMの変化だけに頼らない。
- **台詞:** 物語本編は原則無言。操作案内は短い文字、重要な感情はアニメーションとカメラで見せる。

## 10. 制作・検証の優先順位

1. **物語の理解:** 冒頭30秒を無音・字幕なしで見せ、第三者が「誰のために何を盗むか」を説明できるか確認する。
2. **狛犬の性格:** 鈴だけ、足跡だけ、両方、灯籠盗難後という固定場面を用意し、慎重さと情のある行動に見えるか比較する。
3. **遊びの核:** 境内1区画と帰路だけで、足跡・鈴・灯籠の光が攻略に使えるか確認する。ここまでが最初の縦切り試作。
4. **全編の演出:** 巣と森を加え、モデル・照明・音・カメラの完成基準を一場面ずつ揃える。
5. **終章の頑丈さ:** 発見回数やJev応答失敗が違っても、狛犬が実際に分かる手掛かりを経て巣に到着し、結末がつながるか確認する。
